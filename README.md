# Actividad M2A3: HTML Semántico y Validación W3C

Se refactorizó la estructura del sitio eliminando la sobreutilización de elementos genéricos (`<div>` y `<span>`) y reemplazándolos por etiquetas semánticas de HTML5 (`<header>`, `<nav>`, `<main>`, `<article>`, `<aside>`, `<section>`, `<footer>`). 
Asimismo, se añadieron elementos de texto semánticos como `<time datetime="...">` para fechas legibles por máquinas, `<blockquote>` para citas, `<abbr>` para siglas y `<address>` para la información de contacto, logrando una validación sin errores en el servicio oficial de W3C.
